# Commercial Use of PHANTOM TEMPO

PHANTOM TEMPO™ is intended to be publicly readable and broadly reviewable while preserving commercial licensing rights.

## Free Uses

No commercial license is required to:

- read the framework
- cite the framework
- review or comment on the framework
- use the framework for internal defensive security evaluation
- use the framework for personal research
- use the framework in education or noncommercial research
- discuss the framework in public technical commentary

## Commercial License Required

A commercial license is required before using PHANTOM TEMPO materials in a paid product, service, or commercial offering.

This includes:

- security software products
- SIEM, EDR, XDR, MDR, MSSP, cloud security, identity security, or detection platforms
- paid consulting
- paid assessments or audits
- paid training
- paid reports
- commercial detection packs
- commercial datasets
- commercial schemas or mappings
- marketing claims of PHANTOM TEMPO compatibility, conformance, validation, certification, support, or implementation
